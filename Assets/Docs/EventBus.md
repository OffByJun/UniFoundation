

# **도메인**

도메인은 이벤트 버스의 각 Bus들을 구분 짓는 요소로써  
`EventHub.Instance.Get<TDomain>` 로 가져올 수 있습니다. EventHub에 요청한 TDomain이 존재하지 않을 시 자동으로 생성됩니다.

---

**이벤트 허브**  
이벤트 허브는 이벤트 버스들을 통합 관리하는 Static 인스턴스입니다.  
`EventHub.Instance` 로 접근할 수 있습니다.

API

| 이름 | 호출법                           | 반환값            | 설명                                                                                                    |   
|------|----------------------------------|-------------------|---------------------------------------------------------------------------------------------------------|  
| Get  | `EventHub.Instance.Get<TDomain>` | EventBus<TDomain> | 이벤트 허브에서 도메인을 받아옵니다.<br/>요청한 도메인이 존재하지 않는다면, 새로운 도메인을 생성합니다. |

---

# **이벤트 버스**

이벤트 버스는 단순 요청을 보내기 위한 버스입니다.  
`EventBus<TDomain>` 내부 메서드를 호출하여 접근할 수 있습니다.  
반환값이 필요한 호출은 리퀘스트 버스를 사용하세요.

API

| 이름        | 호출법                               | 반환값 | 설명                                                 |
|-------------|--------------------------------------|--------|------------------------------------------------------|
| Subscribe   | `Subscribe<T>(Action<T> callback)`   | void   | 인자로 넘겨준 함수를 이벤트 버스에 등록합니다.       |
| UnSubscribe | `UnSubscribe<T>(Action<T> callback)` | void   | 인자로 넘겨준 함수를 이벤트 버스에서 등록해제합니다. |
| Publish     | `Publish<T>(T Domain)`               | void   | 등록된 함수를 구독자는 함수들을 호출합니다.          |

---

# **리퀘스트 버스**

리퀘스트 버스는 요청하고 답을 받기 위한 버스입니다.  
Request - Response 구조를 차용하여 입력한 제네릭 인자인 TResult를 Func타입인 handler 변수로 받아옵니다.  
단순 호출은 이벤트 버스를 사용하세요.

API

| 이름       | 호출법                                           | 반환값  | 설명                                             |
|------------|--------------------------------------------------|---------|--------------------------------------------------|
| Register   | `Register<T, TResult>(Func<T, TResult> handler)` | void    | 인자로 넘겨준 함수를 리퀘스트 버스에 등록합니다. |
| UnRegister | `UnRegister<T>()`                                | void    | 인자로 넘겨준 함수를 등록 해제합니다.            |
| Request    | `Request<T, TResult>(T req)`                     | TResult | 등록된 처리자를 호출하고 결과값을 반환합니다.    |
